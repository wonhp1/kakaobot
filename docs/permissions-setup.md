# 권한 설정 (사람이 직접)

봇은 카카오톡 맥 앱의 화면을 **손쉬운 사용(접근성)**으로 읽고 쓴다. macOS 는 이 권한을
**봇을 띄운 앱**에서 찾는다. 터미널에서 `bash scripts/menubar.sh` 를 돌렸으면 터미널,
Claude Code(데스크탑 앱·터미널)에서 띄웠으면 그 앱이다. 메뉴바가 띄운 봇은 메뉴바를 띄운 앱의
권한을 이어받는다.

## 1. 손쉬운 사용 (필수)

시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** → 그 앱을 켠다 (목록에 없으면 `+` 로 추가).

바꾼 뒤에는 그 앱을 **완전히 종료(⌘Q)했다가 다시 연다** — 권한은 앱이 시작할 때 읽힌다.

Claude Code 는 버전마다 경로가 바뀌는 별도 앱으로 돌 수 있다:

```
~/Library/Application Support/Claude/claude-code/<버전>/claude.app
```

목록에 없으면 Finder 에서 `⌘⇧G` 로 위 경로를 열어 `+` 로 추가한다.

## 2. 폴더 접근 (묻는 창이 뜨면 허용)

- 프로젝트 폴더가 데스크탑·문서 폴더 안에 있으면 그 폴더
- **다운로드 폴더** — 질문과 함께 올라온 사진을 카카오톡 '저장하기'로 받아 글자를 읽고 곧바로
  지운다 (`[photo] save_dir`, docs/screenshots.md)

전체 디스크 접근은 필요 없다. 봇은 카카오톡 데이터 파일을 읽지 않는다.

## 3. 카카오톡 창

- 봇이 볼 방을 목록에서 **더블클릭해 별도 창**으로 연다. 최소화하면 안 된다
  (다른 창 뒤에 있거나 화면 밖으로 밀어 둔 것은 괜찮다). 메인 목록 창은 없어도 된다.
- 접근성은 **지금 보이는 데스크탑(Space)** 의 창만 본다. Dock 의 카카오톡 아이콘 우클릭 → 옵션 →
  데스크탑 지정 → **모든 데스크탑**으로 두면 데스크탑을 옮겨 다녀도 봇이 계속 본다.
  창이 안 보이는 동안 봇은 멈추지 않고 기다렸다가, 돌아오면 그사이 질문에 답한다.
- 봇의 답 아래(스레드)에 달린 추가 질문에도 답하려면 **'댓글 알림'** 방도 창으로 연다 (docs/followup.md).

## 4. 확인

```bash
.venv/bin/python -m kakaobot --doctor
```

`손쉬운 사용 권한` 과 `방 창` 이 ✅ 이면 된다.

## 권한 회수

같은 화면에서 그 앱의 토글을 끄거나 `-` 로 지운다.
